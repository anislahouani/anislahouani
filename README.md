## 🚀 Featured Projects

### FlowForge — Warehouse Simulation & Optimization Platform

A full-stack operations intelligence platform for simulating warehouse workflows, identifying bottlenecks, and evaluating capacity decisions.

FlowForge uses discrete-event simulation to model picking and packing operations and compares multiple capacity scenarios to identify cost-effective configurations.

**Key features**

- Discrete-event warehouse simulation
- Picking and packing capacity modeling
- Bottleneck detection
- Throughput and lead-time analysis
- Queue waiting-time analysis
- Capacity optimization
- Cost-per-additional-order analysis
- Interactive performance visualizations
- Automated testing and CI
- Dockerized full-stack deployment

**Stack**

`Python` · `FastAPI` · `SimPy` · `React` · `Vite` · `Recharts` · `Docker` · `Pytest` · `GitHub Actions` · `Vercel` · `Render`

**Live Demo**

https://flowforge-beta-umber.vercel.app

**Repository**

https://github.com/anislahouani/flowforge

### JobTrackr — Job Application Management Platform

A full-stack application for managing and tracking job applications through a centralized dashboard.

Built with a separated frontend/backend architecture, authentication, persistent storage, containerization, and cloud deployment.

**Key features**

- User authentication with JWT
- Job application tracking
- REST API
- Persistent PostgreSQL storage
- Full-stack cloud deployment
- Dockerized backend
